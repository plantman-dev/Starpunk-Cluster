# Starpunk-Cluster
A path into uncharted space.

# Dependencies:
This is really important, so read carefully!
- VertexOblateHeightmap
- VertexMitchellNetravali
- VertexColourMapEmissive
- Kopernicus
And that's it!

# Recommended mods:
- Blackrack's Volumetric Clouds or EVE (for volumetric cloud cover and auroras).
- Scatterer (for more realistic atmospheres, oceans, sunflares and ghosts).
- Deferred (better lighting and performance).
- KSPCommunityFixes (for bug fixes).
