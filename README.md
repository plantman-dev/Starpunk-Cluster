# Dependencies:
This is really important, so read carefully!
- VertexOblateHeightmap
- VertexMitchellNetravali
- VertexColourMapEmissive
- Kopernicus
- Parallax Continued
- ScaledDecorator

## If you want to use wormholes, install:
- Singularity
- Kopernicus Expansion

## If you want rescale (though not suggested), install:
- SigmaDimensions

# Recommended mods:
- Blackrack's Volumetric Clouds or EVE (for volumetric cloud cover and auroras).
- Scatterer (for more realistic atmospheres, oceans, sunflares and ghosts).
- Deferred (better lighting and performance).
- KSPCommunityFixes (for bug fixes).

# Supported mods:
- Full Parallax Continued support
- Full EVE (V5) Support
- Full Scatterer support
- Full Firefly support
- Full PlanetShine support
- SCANsat support
- Kerbalism support
- ResearchBodies support
- MusicSwitcher support (though quite buggy as it’s quite new, it adds the ability to inject custom music!)
- CommunityResourcePack (CRP) support
- Partial SpaceDust support
- DistantObjectEnhancement support
- AdvancedAtmosphereTools support (custom wind)
- DiRT support (custom skybox)
- Note: When Kerbalism, SpaceDust and CRP is installed, I implemented custom SpaceDust resource definitions for Nitrogen and Ammonia, allowing for the direct extraction of gaseous Ammonia & N2 from the atmosphere by SpaceDust processors

Toggleable settings (Located in SC-Main/StarpunkClusterSettings.cfg):
- Rescale support (anything over 2.5x scale I _do not_ recommend)
- Toggleable wormholes
- Distance Scale
